# Statue scan catalog

Era-appropriate sculpture scans for the low-poly statue pipeline
(`scripts/make-low-poly-statue.py`; full recipe in
[../reference/art-pipelines.md](../reference/art-pipelines.md)). Primary
source is threedscans.com (Oliver Laric — published without restrictions),
download links verified live August 2026 (134 catalog entries crawled; 132
live — "Jüngling vom Magdalensberg" and "Right Foot of Fanny Elssler" are
dead; re-checked Aug 7: nothing new posted since, so the crawl is current).
Original-work dates researched Aug 2026 (museum/collection sources;
"unverified" = best guess). Sizes are the compressed download. Baseline:
600 tris, flat-shaded.

**Current focus: works made 1400–1600** — the shortlist below. Everything
else (antiquities, neoclassical, casts) is parked in "Saved for later".

## Saved for later

Renaissance patrons collected antiquities and commissioned all'antica works,
so classical subjects are era-correct almost by definition — these stay
viable, just out of the current focus. 18th–19th-c. neoclassical pieces
(visually indistinguishable at 600 tris) are flagged *(neocl.)*. Several
scans are of plaster casts (Vienna Institut für Klassische Archäologie,
Lincoln) — the date given is the ancient work the cast reproduces.

## Known gaps

- Excluded whole categories: photosculptures, 19th-c. portrait statues
  (Napoleon, Beethoven, Einstein, Tennyson, Wesley, actors), natural-history
  scans (crabs, shells, sea stars, bones), Cambodian plaster casts, armor.

## Pipeline notes

- Full catalog with URLs + liveness: crawl via WP REST (`wp-json/wp/v2/posts`)
  then scrape each entry page for the `stlDL` href — the REST content field
  does not include download links.
- Scans arrive z-up, sometimes upside down, with turntable floaters; the
  script auto-handles all three. OBJ zips can carry a `__MACOSX` sidecar.
- Some scans keep their own socle/base — currently kept (reads as intentional
  base-on-plinth).
